Glosario
==============
- HTML: lenguaje de marcado para paginas web.
- CSS: lenguaje de estilos.
- JavaScript: lenguaje de estilos.
- JavaScript: lenguaje de programacion de la web.
- API: interfaz para comunicar programas.
- Git: sistema de control de versiones.
- Frontend: parte de una web que ve el usuario.
- Backend: parte de una web que funciona en el servidor.
- Framework: conjunto de herramientas para programar mas rapido.
